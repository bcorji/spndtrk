# Project Status
## Day 1: Foundation and database setup.

1. Flutter is the cross-platform frontend.
2. FastAPI provides the backend REST API.
3. PostgreSQL is the relational database.
4. SQLAlchemy handles ORM operations.
5. Alembic manages schema migrations.
6. JWT authentication will be implemented on Day 2.
7. Manual transactions are the primary input method.
8. OCR and AI assist with receipt processing.
9. AI-extracted transactions require user confirmation.
10. User data must remain isolated.
